# Korean Bloom — GitHub Pages

Bản tĩnh không cần database. Bao gồm 3 bài mẫu: 자기소개, 물건 사기, 음식. Bài tập và dữ liệu lưu trực tiếp trong HTML; tiến độ và lịch sử điểm lưu bằng localStorage trên từng trình duyệt.

## Triển khai

1. Tạo repository GitHub, ví dụ `korean-bloom`.
2. Upload `index.html` và `.nojekyll` vào nhánh `main` ở thư mục gốc.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Truy cập `https://TEN-TAI-KHOAN.github.io/korean-bloom/`.

## Lưu ý

Đây là bản demo offline 3 bài, chưa phải 30 bài đầy đủ. Nút tạo đề mở rộng chỉ trộn và biến đổi thứ tự câu hỏi có sẵn; **không phải AI thực**. GitHub Pages không chạy backend hoặc bảo mật OpenAI API key. Không đưa key vào repository. Dữ liệu localStorage không đồng bộ giữa thiết bị và sẽ mất khi xóa dữ liệu trình duyệt.
